# LuaJIT x64 目录

本目录包含特定于x64架构的LuaJIT代码和测试工具。

## 文件说明

- **Makefile** - 该目录的构建脚本，用于构建测试工具和基准测试

## 测试目录 (test/)

测试目录包含x64架构下的测试工具和基准测试程序，用于验证和测量LuaJIT在x64架构上的性能。详见[test目录的README文件](test/README.md)。

## 与主源代码的关系

虽然此目录只包含少量文件，但它与主源代码目录中的`vm_x64.dasc`和`lj_target_x86.h`文件密切相关。这些文件定义了x64架构下的DynASM模板和JIT编译目标代码生成规则。
