# LuaJIT x64 测试目录

本目录包含用于测试和基准测试LuaJIT在x64架构上性能的工具和代码。

## 文件说明

- **Makefile** - 构建测试工具和基准测试程序的脚本

### 测试工具

- **test_util.hpp** - 测试工具的C++头文件，定义通用测试函数和工具类
- **test_util.cxx** - 测试工具的C++实现文件
- **test_util.d** - D语言版本的测试工具实现，可能用于某些特定测试场景
- **test.cpp** - 主测试程序的实现，用于运行各种LuaJIT功能测试

### 基准测试

- **benchmark.cxx** - 基准测试程序的实现，用于测量LuaJIT在x64架构上的性能
- **test_str_comp.lua** - 字符串比较相关的Lua基准测试脚本

## 用途

这些测试工具主要用于：

1. 验证LuaJIT在x64架构上的正确性
2. 对比不同编译选项和优化级别下的性能差异
3. 测试特定功能（如字符串操作）的性能
4. 在开发新功能或修复bug时进行回归测试

## 运行测试

在此目录中执行以下命令可运行测试：

```bash
make test       # 运行功能测试
make benchmark  # 运行基准测试
```
